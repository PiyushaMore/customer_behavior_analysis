# customer_behavior_analysis
This project analyzes customer shopping behavior using Python, MySQL, SQL, and Power BI. The dataset was cleaned and preprocessed using Pandas, stored in MySQL, analyzed using SQL queries, and visualized through an interactive Power BI dashboard to generate meaningful business insights.

📊 Data Analytics Project
Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data collection to business insights. It covers data loading, cleaning, exploratory data analysis (EDA), SQL-based analysis, interactive dashboard creation in Power BI, and presentation of findings through a report and presentation.

The objective is to transform raw data into meaningful insights that support data-driven decision-making.

Dataset

The project uses a structured dataset containing business-related information for analysis.

The dataset was used to:

Understand data structure and quality
Clean missing and duplicate values
Perform exploratory data analysis (EDA)
Extract insights using SQL
Build an interactive Power BI dashboard
